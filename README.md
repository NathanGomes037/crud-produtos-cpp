# crud-produtos-cpp
Crud de produtos desenvolvido em c++ ultilizando vetores, funções e estruturas de controle
## tecnologias usadas nesse CRUD
-C++
-vetores (arrays)
-funçoes 
-estrutura de condição
-estrutura de repetição
## como executar
1. compile o arquivo 'crud.cpp'
2. execute o programa
3. e escolha uma opção no programa
4. use a opção desejada
5. caso queira fechar aperte o numero 5 no menu
## objetivo
aplicar meu aprendizado sobre vetores, fuções e estruturas de condições e repetições em algo pratico para poder fixar melhor o aprendizado
